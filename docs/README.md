# ProofMesh Documentation Architecture

This directory serves as the centralized documentation repository for ProofMesh. All architectural decisions, product specifications, API contracts, security reviews, and phase reports are maintained here.

## Directory Index

| Directory | Scope & Purpose |
| :--- | :--- |
| [`product/`](./product/README.md) | Product requirements, playbooks, user journeys, and traceability matrix |
| [`architecture/`](./architecture/README.md) | High-level system architecture, component diagrams, and domain boundaries |
| [`adr/`](./adr/README.md) | Architectural Decision Records (ADRs) tracking significant design choices |
| [`api/`](./api/README.md) | OpenAPI/AsyncAPI specifications, contract definitions, and interface guides |
| [`data-model/`](./data-model/README.md) | Entity-relationship diagrams, schema definitions, and migration strategies |
| [`security/`](./security/README.md) | Threat models, security review sign-offs, and compliance documentation |
| [`testing/`](./testing/README.md) | Testing strategies, verification matrices, and benchmark benchmarks |
| [`operations/`](./operations/README.md) | Runbooks, deployment guides, configuration reference, and failover behavior |
| [`research/`](./research/README.md) | Research analyst briefs, external API evaluations, and library audits |
| [`phase-reports/`](./phase-reports/README.md) | End-of-phase verification reports, test outputs, and sign-offs |
