# Security Architecture & Threat Models

This directory contains security documentation, threat modeling analyses, tenant boundary validations, and formal security review sign-offs.

## Scope

- **Threat Modeling**: STRIDE / DREAD threat assessments across AI governance pipelines, webhook endpoints, and data stores.
- **Tenant Isolation Audits**: Verification reports confirming complete cross-tenant isolation at server and database layers.
- **Untrusted Content & Model Defense**: Security protocols governing ingestion of untrusted documents, prompts, and model outputs.
- **Cryptographic Specifications**: Detailed standards for evidence hashing, digital signatures, and audit log tamper-evidence.
